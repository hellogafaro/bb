# Snooze attribution

The status organization's snooze rules follow GTD Sidebar by Scott Sunarto,
licensed under the MIT License:
https://github.com/smsunarto/bb-plugins/tree/main/plugins/gtd-sidebar

See `licenses/GTD-SIDEBAR-MIT.txt`. The Thread list reimplements the wake rules
(the time passed, new activity, never hide working or waiting threads). No GTD
Sidebar code runs at runtime.
